# Zairai

ไซไร (Zairai — 在来) จริง ๆ แปลว่า Native หรือ Conventional เป็นคำที่ใช้เรียกต้นชาที่ปลูกด้วยการหว่านเมล็ด
และไม่ได้ผ่านการขยายพันธุ์แบบโคลนเหมือนต้นชาในอุตสาหกรรมชาส่วนใหญ่ในปัจจุบันครับ
ต้นชา Zairai แต่ละต้นมีพันธุกรรมที่แตกต่างกัน ทำให้ไม่มีรสชาติหรือบุคลิกที่คาดเดาได้
แต่จะสะท้อนความแตกต่างของพื้นที่ปลูก สภาพอากาศ และการดูแลในแต่ละปีออกมาได้อย่างชัดเจน

ชาตัวนี้มาจากกลุ่มต้นชาที่มีอายุเฉลี่ยมากกว่า 60 ปี ปลูกจากเมล็ดที่รวบรวมจากพื้นที่ตะเข็บจังหวัดเกียวโตและจังหวัดนาระ
ที่ระดับความสูงประมาณ 150 เมตร และผ่านการพรางแสงประมาณ 18–21 วันก่อนเก็บเกี่ยวครับ จากข้อมูลที่เราได้รับมา
บริเวณแปลงปลูกเป็นเนินดินลาดชันที่มีมาตั้งแต่สมัยดึกดำบรรพ์ มีการสะสมของอินทรียวัตถุในปริมาณสูงมาก
จากการเปลี่ยนแปลงของวัฏจักรโลกตั้งแต่ยุคก่อนประวัติศาสตร์จนถึงปัจจุบัน
โดยเกษตรกรยังคงปลูกชาบนพื้นที่ลาดชันแทนการปรับพื้นที่ให้เป็นที่ราบ เพื่อรักษาหน้าดินเอาไว้ ด้วยเงื่อนไขนี้
จึงต้องอาศัยแรงงานคนในการดูแลจัดการไร่เกือบทั้งหมด

ชาที่ปลูกจากเมล็ด แม้จะมีความไม่แน่นอนในด้านผลผลิต แต่ก็ให้ความเป็นธรรมชาติและความตื่นเต้นในการชิมดีนะครับ
ก่อนจะถูกนำมาบดเป็นมัทฉะ ใบเท็นฉะของชาตัวนี้ใช้เวลาพักแบบบ่มเย็นค่อนข้างนานครับ ซึ่งช่วยให้รสขมนิ่งขึ้น
และทำให้ความฝาดที่มาพร้อมโทนเปรี้ยวช่วงต้นนุ่มลง รสชาติจึงมีความกลมขึ้น อูมามินุ่ม หวานเนียน และดื่มเพลินครับ

มัทฉะตัวนี้ให้กลิ่นคล้ายป่าสน มอส และช่อดอกไม้ พร้อมความหอมหวานแบบผลไม้ญี่ปุ่นหลายชนิด
มีความฝาดเปรี้ยวคล้ายเปลือกแอปเปิลเขียวและเปลือกเลมอน

เมื่อชงกับนม จะได้ความนุ่มกลม รสอูมามิที่เด่นขึ้น พร้อมความครีมมี่และนัตตี้มากขึ้นครับ
เราเลือกเสิร์ฟแบบมัทฉะลาเต้ความเข้มระดับเข้มมาก (ซึ่งเราไม่ได้มีชาใหม่ที่นำมาเสิร์ฟด้วยความเข้มระดับนี้มานานแล้ว)
และเสิร์ฟกับนมถั่วเหลืองครับ หากมาที่หน้าร้าน เราจะมีตัวเลือก Classic Latte แบบเบา สดชื่น ไว้บริการด้วยครับ

โดยรวมแล้ว Zairai เป็นชาที่น่าสนใจมากครับ แม้อาจจะไม่ใช่ชาตัวแรกสำหรับใครหลาย ๆ ท่าน
แต่ก็คิดว่าน่าจะเป็นอีกหนึ่งประสบการณ์ที่ดีครับ สำหรับท่านที่อยากลองชาญี่ปุ่นที่มีความเป็นธรรมชาติ สนุก น่าตื่นเต้น
หาทานยาก และแตกต่างจากชาสายพันธุ์หลักที่พบทั่วไป ก็ขอแนะนำและเรียนเชิญครับผม
