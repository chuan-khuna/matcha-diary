# Kyôken-283

เคียวเคน-283 (Kyôken-283 — 京研283) หนึ่งในสายพันธุ์ชาจากเกียวโตที่น่าสนใจ กลับมาแล้วครับ
แม้ชื่ออาจจะไม่ได้ดังและคุ้นหูเหมือน Asahi, Ujihikari หรือ Samidori
แต่ก็เป็นสายพันธุ์ที่อยู่ในวงการวิจัยและการพัฒนาอุตสาหกรรมชาของเกียวโตมาอย่างยาวนานครับ
ด้วยเอกลักษณ์ของสายพันธุ์ที่สามารถสร้างรสอูมามิได้ดี และมีโครงสร้างรสชาติที่แน่น ทำให้ Kyôken-283
ถูกนำมาพัฒนาในกลุ่มผู้ผลิตที่สนใจการทำเทนฉะสายพันธุ์เฉพาะมากขึ้นในช่วงหลายปีที่ผ่านมาครับ

ชาตัวนี้มาจากพื้นที่คาเมะซึกะ (Kamazuka) ในเมืองวาซุกะ (Wazuka) จังหวัดเกียวโต
ซึ่งเป็นหนึ่งในพื้นที่ปลูกชาที่สำคัญของชาอุจิ (Uji-cha)
และเป็นพื้นที่ที่มีการปลูกวิธีการทำชาแบบอุตสาหกรรมควบคู่กับการทดลองสายพันธุ์ใหม่ ๆ อยู่ครับ

ความน่าสนใจของ Kamazuka คือภูมิประเทศที่เป็นพื้นที่ภูเขา
มีแปลงชาตามแนวเนินและได้รับอิทธิพลจากสภาพอากาศที่แตกต่างกันระหว่างกลางวันและกลางคืน
ช่วยให้ต้นชาค่อย ๆ เติบโตและพัฒนาความเข้มข้นของรสชาติได้ดี

สำหรับล็อตนี้ ต้นชาถูกพรางแสงประมาณ 5-6 สัปดาห์ก่อนการเก็บเกี่ยว เพื่อเพิ่มความเข้มของสี กลิ่น
และสร้างรสอูมามิของ Kyôken-283 ออกมาให้ชัดขึ้นครับ

Kyôken-283 ตัวนี้เป็นมัทฉะที่มีสไตล์แน่น ลึก และมีความ savory อยู่มาก
เมื่อชงเป็นแบบไม่ใส่นม จะให้รสอูมามิที่เต็มและชัดเจน มีบอดี้ที่แน่น พร้อมกลิ่นคล้ายถั่วเขียว กะหล่ำดาว
และหัวไชเท้าญี่ปุ่น มี Earthy note ที่ช่วยเพิ่มมิติ
ทำให้รู้สึกคล้ายกับรสชาติของผักเขียวและรากพืชที่ผ่านการปรุงอย่างละเอียด

เมื่อเปลี่ยนเป็นชงกับนม ชาจะเปิดรสอีกด้านหนึ่งครับ ความขมและความเขียวจะถูกทำให้นุ่มลง
พร้อมดึงกลิ่นของถั่วแดงต้มและเผือกต้มออกมา ให้ความรู้สึกคล้ายขนมญี่ปุ่นที่ทานคู่กับชา
หรือจะชงกับนมโอ๊ตและนมถั่วเหลือง ก็ยังคงมีความอูมามิและ Earthy พร้อมโน้ตของถั่วลิสงต้มและเผือก
หรือ ถั่วแดงและแป้งหวาน ๆ อย่างชัดเจนครับ
