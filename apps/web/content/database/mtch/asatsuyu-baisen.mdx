# Asatsuyu Baisen

มัทฉะสายพันธุ์อะสัตสึยุ (Asatsuyu — あさつゆ) จากเมืองคิริชิมะ จังหวัดคาโกชิมะ
ที่นำมาผ่านกระบวนการอบเพิ่มแบบพิเศษ เพื่อสร้างมิติของกลิ่นหอมคั่วที่โดดเด่น
แต่ยังคงรักษาความสดชื่นและเอกลักษณ์ความอูมามิของสายพันธุ์ไว้ได้อย่างครบถ้วนครับ

ชาตัวนี้ปลูกแบบออแกนิค และพรางแสงด้วยผ้าใยสะท้อนแสงสีเงินเช่นเดียวกันกับตัวปกติทุกอย่างครับ
แต่สิ่งที่ทำให้ตัวนี้แตกต่างคือการใช้เทคนิคไล่ความชื้นและดึงความหอมด้วยความร้อนเพิ่มเติมก่อนบด
จนเกิดคาแรคเตอร์ที่ชัดเจนและมีมิติของความหอมจากการอบที่จัดจ้านยิ่งขึ้นครับ

Asatsuyu Baisen ให้กลิ่นที่อุ่นนวล ยังคงความสดชื่นตามสไตล์อะสัตสึยุ
แต่โดดเด่นด้วยกลิ่นธัญพืชคั่วอบที่หอมฟุ้งขึ้นมา ก่อนจะตามมาด้วยความหวานมันแบบมะพร้าวเผา, โกโก้
และพิสตาชิโอ แฝงอยู่อย่างน่าสนใจ ก่อนทิ้งความเต็มรส หวาน ขม ฝาด สดชื่นยาวนานไว้ในลำคอครับ
