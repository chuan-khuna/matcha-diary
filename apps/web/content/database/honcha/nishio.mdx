# Nishio

มัทฉะจากเมืองนิชิโอะตัวนี้ คือเซเรโมเนียลตัวแรก ที่ผมเลือกมาเก็บไว้ให้พอร์ทของฮงฉะ ไม่ได้เป็นสายพันธุ์เดี่ยว แต่เป็นการเบลนด์จาก 3 สายพันธุ์ คือ ซะเอะมิโดะริ ยะบุคิตะ และ โอะคุมิโดะริ จากทุกตัวที่ผมมี มัทฉะนิชิโอะขึ้นชื่อความละเอียดของผง ความฟูเวลาตีมากที่สุด ให้กลิ่นหอม ไม่มีความเป็นถั่วหรือสาหร่าย มีความเป็นกลางสูง ถ้าลูกค้าต้องการดื่มด่ำรสชาติที่แท้จริงของมัทฉะ ผมจะแนะนำลูกค้าให้เลือกตัวนี้เสมอ สามารถชงได้ทั้งเคลียร์และลาเต้
