# Uji Okumidori

โดยปกติแล้วที่เรารู้ๆกัน ว่ามัทฉะจากอุจิ จะมีความเป็นสาหร่ายเป็นส่วนใหญ่ แต่ก็มีบางไร่ ที่สามารถดีเวลลอปให้มัทฉะมีความเป็นถั่วได้ ไม่ได้มีความเป็นถั่วคั่ว หรือถั่วไหม้ แต่ให้ความเป็นถั่วที่ดื่มง่าย

มัทฉะ อุจิ โอะคุมิโดะริตัวนี้ ผมใช้เวลาหลายปีกว่าจะได้มา เป็นสายพันธุ์เดี่ยวของโอะคุมิโดะริของอุจิ ที่มีความเป็นถั่ว ใน 1 ปี ผลิตได้จำนวนไม่มากนัก ให้สีเขียวสดที่สวย กลิ่นหอมของถั่วอ่อนๆ มีความอุมามิสูง

สามารถชงได้ทั้งเคลียร์ และ ลาเต้
