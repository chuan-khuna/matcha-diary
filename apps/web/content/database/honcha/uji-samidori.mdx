# Uji Samidori

มัทฉะอุจิ โอะคุมิโดะริที่ว่าผลิตได้น้อยแล้ว มัทฉะอุจิ ซะมิโดะริผลิตได้น้อยยิ่งกว่า เนื่องจากเป็นสายพันธุ์ที่ต้องการการดูแล้เป็นพิเศษที่มากกว่าสายพันธุ์อื่น ทำให้ในแต่ละปี ผลผลิตที่สามารถนำมาทำเป็นมัทฉะยิ่งน้อยลง

สายพันธุ์เดี่ยวซะมิโดะริของอุจิตัวนี้ เป็นอีกหนึ่งตัว ที่ไม่อยากให้คนที่ชอบดื่มเคลียร์พลาด สำหรับคนที่ชอบความลึกลับของรสชาติ อุจิ ซะมิโดะริทำให้ผมติดอยู่ในวังวนนั้นอยู่นานแสนนาน เป็นอาฟเตอร์เทสต์ที่ไม่มีมัทฉะตัวไหนทำได้

สำหรับตัวนี้ ผมเชียร์ให้ดื่มเคลียร์ครับ แต่ลูกค้าหลายๆท่าน ก็นำไปทำเป็นลาเต้ ก็ยังอร่อยเช่นกัน
