# Midori

The Yame powder that is defined by what it is not: the Thai line says ไม่สโม๊ค — no smoke —
which in a range where four of five list it is the distinguishing fact rather than an omission.

What is left is body. Nutty, round, creamy, umami, with none of the top note the others carry.

No cultivar is published, so this record carries none.
