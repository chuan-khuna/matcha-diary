# Hoshi02

The second Hoshinomura lot, at the same 1,190 as the first and with the same five notes listed
against it. The one word that changes is the qualifier: smoky becomes *slight* smoky, and the Thai
line softens with it — smoke in the round rather than smoke at the front.

Sitting beside Hoshi is the whole point of the pair. Same village, same price, same vocabulary,
one dial moved.

No cultivar is published, so this record carries none.
